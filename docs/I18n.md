# 🌍 UltraLean Framework — Internationalization (i18n)

UltraLean provides a **high-performance, zero-overhead multilingual system** designed for:

* ⚡ Pure PHP speed (no runtime overhead)
* 🧠 Deterministic behavior (no guessing)
* 🔌 Optional usage (disabled = zero cost)
* 🗄️ Seamless DB + file translation support

---

# 📁 Configuration

## File

```
/apps/default/config.php
```

## Example

```php
'i18n' => [

    'enabled' => true,

    'default' => 'en',
    'fallback' => 'en',

    'supported' => ['en', 'ur', 'ar'],

    'path' => APP_PATH . '/lang',

    'resolver' => [
        'session' => true,
    ],

    'database' => [
        'enabled' => true,
        'strategy' => 'join',
        'fallback_in_php' => true,
    ],
],
```

# 🌐 Locale Management

## Class

```
UltraLean\Core\I18n\Locale
```

---

## 🔹 Methods

### `Locale::set(string $locale): void`

Set the current application locale.

```php
Locale::set('ur');
```

✔ Stores in session (if enabled)
✔ Validates against supported locales

---

### `Locale::get(): string`

Get the current resolved locale.

```php
$locale = Locale::get();
```

### Resolution Priority:

1. Manually set locale
2. Session
3. Default (config)

---

### `Locale::clear(): void`

Reset locale (clears session + memory cache)

```php
Locale::clear();
```

---

## 🔹 Example

```php
use UltraLean\Core\I18n\Locale;

// Set language
Locale::set('ar');

// Get language
echo Locale::get(); // ar
```

# 📖 Translator (File-Based Translations)

## Class

```
UltraLean\Core\I18n\Translator
```

---

## 📁 Directory Structure

```
/apps/default/lang/

    en/
        messages.php

    ur/
        messages.php
```

---

## 📄 Example Language File

```php
// lang/en/messages.php
return [
    'welcome' => 'Welcome',
    'user' => [
        'greeting' => 'Hello :name',
    ],
];
```

---

## 🔹 Methods

### `__construct()`

Auto-initializes:

* Current locale
* Fallback locale
* Language path

---

### `get(string $key, array $replacements = []): string`

Fetch translation using dot notation.

```php
$t = new Translator();

echo $t->get('messages.welcome');
```

---

## 🔹 Nested Keys

```php
echo $t->get('messages.user.greeting', [
    'name' => 'Ali'
]);

// Output: Hello Ali
```

---

## 🔹 Fallback Behavior

If key not found in current locale:

→ fallback locale is used
→ if still missing → key is returned

```php
echo $t->get('messages.unknown');
// Output: messages.unknown
```

---

## 🔹 Change Locale at Runtime

```php
$t->setLocale('ur');

echo $t->get('messages.welcome');
```

# ⚡ Helper Function

## File

```
/system/helpers.php
```

```php
function __($key, array $replace = []): string
{
    static $t;

    if (!$t) {
        $t = new \UltraLean\Core\I18n\Translator();
    }

    return $t->get($key, $replace);
}
```

---

## Usage

```php
echo __('messages.welcome');

echo __('messages.user.greeting', [
    'name' => 'John'
]);
```

# 🗄️ Database Translations

UltraLean supports **high-performance JOIN-based translations**.

---

## 🧱 Table Structure

### Base Table

```sql
posts
- id
- slug
```

### Translation Table

```sql
post_translations
- id
- post_id
- locale
- title
- content
```

---

## ⚡ Required Index (IMPORTANT)

```sql
CREATE UNIQUE INDEX idx_post_locale
ON post_translations (post_id, locale);
```

---

# 🧠 Model Translation Support

## Example Model

```php
class Post extends Model
{
    protected static string $table = 'posts';

    protected static ?string $translationTable = 'post_translations';
    protected static string $translationForeignKey = 'post_id';
}
```

---

## 🔹 Methods

### `findWithLocale($id, $locale)`

```php
$post = Post::findWithLocale(1, 'en');
```

✔ Single query
✔ Uses LEFT JOIN
✔ Fast and efficient

---

### `insertWithTranslations(array $data, array $translations)`

```php
Post::insertWithTranslations(
    ['slug' => 'hello-world'],
    [
        'en' => ['title' => 'Hello'],
        'ur' => ['title' => 'ہیلو'],
    ]
);
```

✔ Transaction-safe
✔ Inserts base + translations

---

# 🔗 Query Builder Translation

## Enable Locale

```php
Post::query()
    ->locale('en')
    ->get();
```

---

## Example

```php
$posts = Post::query()
    ->select(['t.id', 'tr.title'])
    ->locale('ur')
    ->where('t.id', '>', 10)
    ->get();
```

---

## Generated SQL (Simplified)

```sql
SELECT t.id, tr.title
FROM posts t
LEFT JOIN post_translations tr
    ON tr.post_id = t.id
    AND tr.locale = 'ur'
WHERE t.id > 10
```
